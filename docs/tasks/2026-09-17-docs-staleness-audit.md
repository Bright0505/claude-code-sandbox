## 回退方式

全部是文件改動，切成三個 commit（禁令 6），各自可獨立 `git revert`：
過時更正（C1-C7）／出貨檔的 ID 改寫（C8-C9）／事故紀錄（C10）。
沒有產品程式碼、沒有腳本邏輯、沒有出貨清單的變動，所以不影響 `main` 與既有 tag。

⚠️ revert C8-C9 會讓上游專屬 ID 回到出貨檔裡；revert C10 會讓 `K-10`／`K-11`
消失，但編號**不重用**（`record` §3）—— 之後要重開得從 `K-12` 起。
